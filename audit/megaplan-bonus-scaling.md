# MEGAPLAN: динамическая бонусная экономика («финальный спринт» — комбэк-механика)

> **Статус: РЕАЛИЗОВАНО** (коммит `bd08fb1`). Проверки: `audit/tool/verify14.js` 37/37, регрессии verify2 67/67, verify3 43+2 известных, verify4 21/21.

## Контекст и цель

**Проблема:** у отстающего игрока не было инструментов камбэка — исход игры часто предрешён за несколько раундов до конца. Бонусное слово давало фиксированные +25p и всегда было одно.

**Решение (согласовано):** награда за бонусное слово и их количество растут ступенями к финалу; способности магов перебалансированы под новую экономику.

## Механика

Прогресс игры `p = currentRound / totalTurns` делит игру на 3 фазы:

| Фаза | Условие | ✨-слов | Награда | Пример (7 раундов) |
|---|---|---|---|---|
| 0 | p ≤ 0.5 | 1 | +25p | раунды 1–3 |
| 1 | 0.5 < p ≤ 0.8 | 2 | +50p | раунды 4–5 |
| 2 | p > 0.8 | 3 | +100p | раунды 6–7 |

- Каждое ✨-слово помечено и даёт награду, но за ход объясняется одно слово — это **выбор**, а не стекинг.
- Кап `min(count, targetCount − 1)` гарантирует ≥1 лёгкое слово в списке («безопасные» +100p).
- Работает для любой длины игры (2/5/7/10/15/20). Демо 2 раунда: r1 → фаза 0, r2 → фаза 2.
- Бонусы +50 (arvaaja в 3p, ryöstö в 4p) и тема `vapaavalintainen` — без изменений.

## Ребаланс магов

- **Sanakaaos** (Kirouksenlangettaja): 3 слова цели заменяются **💀-проклятыми** словами из kaikkisanat — сложные, но БЕЗ бонусной награды. Поздней игрой проклятие блокирует раздутую бонус-экономику хода — настоящий контр-плей.
- **Sanametamorfoosi** (Muodonmuuttaja): новый список генерируется по тем же фазовым правилам — бонусные слова сохраняются. Базовая награда остаётся 50p. Побочный эффект — **снимает Sanakaaos** (обмен заряд на заряд, контр-плей в 3p). Проклятие размера (Korttinälkä, −2 слова) метаморфоза НЕ снимает.
- **Korttitulva / Korttinälkä / Kasvupurkaus** — без изменений кода; взаимодействия сбалансированы естественно (Korttinälkä поздней игрой уменьшает и число бонусных слов через кап).

## Архитектура

- `js/state.js`: `currentBonusWordText` (строка) → `currentBonusWords[]` (✨) + `currentCursedWords[]` (💀).
- `js/rounds.js`: `BONUS_PHASES` + `getBonusPhase()`/`getBonusConfig()`; единый `generateWordList(withChaos)` → `{words, bonusWords, cursedWords}` — используется и `switchToWords` (withChaos=true), и метаморфозой (false = очищение).
  - `generateWordList` фильтрует оба словаря через `Set(usedWordsInThisGame)` — инцидентальный фикс: массив раньше только писался (слова могли повторяться между раундами; метаморфоза фильтровала, обычная генерация — нет). Фолбэк без фильтра при исчерпании частотного пула.
  - `endRound`: бонус = `getBonusConfig().value` при совпадении выбранного слова с `currentBonusWords`; `isMetamorphosisUsedThisTurn` больше не отключает бонус (осталась только урезанной базой 50p). Заработанный бонус уходит в `ROUND_END` как `bonus`.
  - `switchToWords` вызывает `updateTurnDisplay()` — индикатор фазы всегда актуален.
- `js/spells.js`: обработчик метаморфозы — `generateWordList(false)`, снятие `chaosFourWords` + скрытие `#curseBanner`. Косметическое ограничение «уникальная первая буква» удалено (генератор уже перемешивает).
- `js/ui.js`: `renderOlList` — мульти-✨-бейджи `+{V}p` по фазе, 💀-бейджи проклятых (`data-cursed`, `data-rare="false"`); `bonusHint` динамический (бонус / каос / пусто); `formatRoundCounter()` → `Kierros: X / Y · ✨+Vp` в `#roundDisplay`; `updateGuessedButtonsText` — превью реальной выплаты (`+200p` при зажатом ✨ в финале); обновлены `spellDescriptions`.
- `js/network.js`: `#ngRound` через `formatRoundCounter()`; `bonus` в payload ROUND_END и строка `✨ Bonussana! +Vp` в сводке; `netCleanupTurnUI` очищает оба массива.
- `js/main.js`: `resetCurrentGame` сбрасывает оба массива; клик по слову → `updateGuessedButtonsText()`.
- `styles.css`: `.curse-badge` + скрытие под `.hidden-words`.
- `index.html`: правила (Bonussanat +25→+100p), magicGuide, char-pills (Sanametamorfoosi, Sanakaaos), дефолтный `#bonusHint`.

## Сетевой аспект

Слова/бонусные слова не покидают устройство объясняющего (`WORDS_OPEN` несёт только count); счёт считает объясняющий и рассылает готовый `ROUND_END.scores` — масштабирование синхронизируется бесплатно. Протокол не меняется (только +`bonus` в сводке).

## Проверка

- `audit/tool/verify14.js` — **37/37**: границы фаз (0.5/0.8 включительно), генерация 1/2/3 ✨-слов, бейджи +25/+50/+100, кап ≥1 лёгкого, Sanakaaos (3 💀, 0 ✨, +0 бонуса), Sanametamorfoosi (бонусы сохраняются, каос снят, база 50+25=75), скоринг +125/+200/+100, превью выплаты, индикатор раунда, демо 2 раунда.
- Регрессия: verify4 **21/21** (B3 «koko sanakirjasta +25p» проходит — на 1-м раунде текст тот же), verify2 **67/67**, verify3 **43+2** (оба фейла — задокументированные предсуществующие: emoji-тема у гостя после Task 11).

## Подводные камни

- `getBonusConfig()` живо читает `currentRound` — в `endRound` награда начисляется ДО инкремента раунда, так что фаза = фаза генерации. При переносе логики следить за порядком.
- `chaosFourWords` снимается метаморфозой — осознанный контр-плей, не баг. `reduceToThree` намеренно остаётся (уменьшенный список сохраняется).
- `data-rare="false"` у проклятых слов — тест `verify3` выбирает их для детерминированного счёта: очков нет, поведение корректно.
- `bonusHint` на 1-м раунде по-прежнему содержит «koko sanakirjasta» и «+25p» — это поддерживает совместимость verify4 B3.
