# MEGAPLAN: способности над колесом — пилюля «Näytä sanat» больше не перекрывает спеллы

> **Статус: РЕАЛИЗОВАНО**. Проверки: `audit/tool/verify19.js`; регрессия `verify16.js`, `verify17.js`.

## Диагноз

**Симптом:** после остановки тематического колеса кнопка способности фазы 1 физически закрыта плавающей пилюлей «👁️ Näytä sanat» — её невозможно нажать.

**Измерено (390×844, магия вкл, колесо в `.drum-rest`):**
- `#btnDisplayWords` — `position:fixed; bottom:60px; z-index:20` → 722–784px.
- `#loader` (колесо) — 147–655px.
- `#spellContainer` (`order:3`) — 688–766px: spell row на 720–765px, `elementFromPoint` → `#btnDisplayWords`. Перекрытие ~44px по высоте — почти вся кнопка.

**Корень:** `#gameContainer` — flex-column с order-раскладкой (`paneli 1 → loader 2 → spells 3 → wordList 5 → controls 6 → #btn 7`, Task 24). Спелл-зона рендерилась ПОД колесом — ровно в зону фиксированной пилюли.

## Решение

`#spellContainer { order: 3 → 1 }` — спелл-зона входит в группу «над колесом». Среди order-1 элементов (`turnPanel → themeBlock → spellContainer` по DOM) она встаёт последней — **ровно над `#loader`** (order 2).

Итоговая раскладка при отдыхающем колесе:
```
[chips/turnPanel] → [theme card] → [✨ Taikuus + spell rows] → [колесо у низа] → [пилюля над нижним краем колеса]
```

`#loader { margin-top:auto }` приклеен к низу — при появлении спеллов после остановки само колесо не дёргается, зона встраивается между темой и колесом.

## Что не менялось и почему

- `#btnDisplayWords` — фикс. пилюля по дизайну (thumb-reach, blur). Для `vapaavalintainen` она не показывается → `#vapaaRuleCard` (order 4, намеренно под колесом) перекрытий не имеет — проверено измерением.
- `#curseBanner` (order 0) — верх экрана, существующее поведение.
- Фаза 2 («Sanojen aikana», метаморфоза): тот же `#spellContainer` — в `words-active` `#themeBlock` скрыт, зона оказывается под turn-panel (там же, где была).
- JS без правок — видимость по `style.display`, от DOM-порядка не зависит.

## Архитектура

- `styles.css` (~1660): `#spellContainer { order: 1 !important }` + комментарий-предупреждение об инварианте DOM-порядка.
- `order:2` НЕ годился бы: ничья с `#loader` решается DOM-порядком (loader раньше) → спеллы снова под колесом.

## Проверка (`audit/tool/verify19.js`)

- A) Колесо остановлено: спелл-зона видима, `spellBox.bottom ≤ loader.top`, все видимые `.spell-action-row` хит-тестятся в себя (не пилюля).
- B) Пилюля живая: видна, хит-тест в себя, висит над нижним краем колеса.
- C) Фаза 2: спелл-зона над `#wordListWrap`, кнопка метаморфозы кликабельна, пилюля скрыта.
- D) Без магии: спелл-зоны нет, пилюля работает, слова открываются.
- E) Комната: у объясняющего (хост) та же раскладка — зона над колесом, без перекрытий.
- F) Zero console errors.
- Регрессия: verify16 (wheel-rest), verify17 (sticky bar, words-active).

## Подводные камни

- Инвариант: `#spellContainer` в DOM должен оставаться ПОСЛЕ `#themeBlock` — иначе order:1 не даст «ровно над колесом». Зафиксировано в CSS-комментарии.
- При `words-active` зона спеллов фазы 2 остаётся под turn-panel — позиция не изменилась (themeBlock тогда скрыт).
- Пилюля намеренно перекрывает нижний край колеса (дизайн Task 24) — проверка B страхует, что она при этом кликабельна.
